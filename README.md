# Astra Effort

Repositório local de estudo e experimentação com os recursos do **GPT-6 Astra Effort Super Guide**, de Mark Kashef / Early AI Dopters.

O kit original foi importado integralmente, com seus arquivos em inglês preservados. Os arquivos descompactados estão na raiz para facilitar a leitura; os downloads originais estão em `files/`.

## Comece aqui

1. Abra o [guia em PDF](Astra-Effort-Super-Guide.pdf) ou a [versão em Markdown](SUPER-GUIDE.md).
2. Consulte as [instruções originais](START-HERE.md).
3. Escolha um dos [10 prompts](PROMPTS.md), também disponíveis individualmente em [prompts/](prompts/).
4. Explore os [resultados em CSV](evidence/results.csv) ou [JSON](evidence/results.json).
5. Para registrar um experimento próprio, copie [YOUR-RUN-LOG.csv](experiment/YOUR-RUN-LOG.csv) e consulte a [tarefa original](experiment/ASSIGNMENT.txt) e suas [condições de execução](experiment/EXECUTION-CONDITIONS.txt).

Não é necessário instalar dependências para ler o material. Os arquivos `.excalidraw` podem ser abertos no Excalidraw; CSV e JSON podem ser abertos em planilhas e editores compatíveis.
